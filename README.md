# springboot-thymelead-web-app
# Employee Management System

This is a web application developed using **Java Spring Boot, Thymeleaf, and MySQL** to manage employee records.

## Features

* Add new employee
* View employee list
* Update employee details
* Delete employee
* Pagination for employee list

## Technologies Used

* Java
* Spring Boot
* Thymeleaf
* MySQL
* Spring Data JPA
* Bootstrap

## How to Run

1. Clone the repository
2. Configure MySQL database in `application.properties`
3. Run the application using Spring Boot
4. Open browser and go to: `http://localhost:8080/`

## Description

This project demonstrates CRUD operations and pagination using Spring Boot and Thymeleaf. It follows MVC architecture and uses JPA for database interaction.
